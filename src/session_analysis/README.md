\# TikTok Session Analysis



\## How to run the analysis



1\. Open the project in Positron.

2\. Make sure the required R packages are installed.

3\. Open the terminal in the project root folder.

4\. Run:



```bash

make

```



The Makefile will:



\* Download the session data into the `data` folder.

\* Run the session analysis.

\* Create three `.png` visualizations in the `fig\_outputs` folder.



The analysis uses the session data stored in the `data` folder.
