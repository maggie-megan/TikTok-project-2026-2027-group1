# Watch rate Analysis

## Author: Merel van Buren
 
## The goal of the project
Clean and analyze data about TikTok Watch Rates.

## Environment & dependencies 
### Folder structure
In the folder data, you can find the csv file on the watch events. In the file data_script, you can find the script on the R commands to download the data. in the file r_script, you can find the coding for cleaning the data and making the plots. The plots themselves can be found in the folder called output.

### Dependencies
You will need:
* tidyverse
* dyplr
* ggplot2

## Reproduction of the analysis 
You can run the makefile. Otherwise, please get the data using the data_script, and then proceed with the r_script.
